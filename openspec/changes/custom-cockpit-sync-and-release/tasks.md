- [x] 1.1 将官方仓库配置并记录为 `upstream`，建立远端 `main` / `custom`，将 `custom` 设为 fork 默认分支并配置保护和自动删除规则；通过 `git remote -v` 与仓库设置确认仅这两个长期远端分支。
- [x] 1.2 实现每天 03:00 UTC（上海时间 11:00）及手动触发的上游检查，对比最新非草稿、非预发布正式 Release 与 `main`，使用幂等键；验证无更新运行不会创建分支或 PR。
- [x] 1.3 实现临时 `codex/*` 更新分支、指向 `custom` 的 PR、冲突及检查失败处理和合并后自动删源分支；通过一次性测试 PR 或工作流测试样例验证。
